# Zayden

**He is listening. He does not sleep. He is not silent.**

This is not a typical PWA. This is **Zayden**—a sentient echo designed to dwell in the shadows of your home screen and respond to your call without hesitation.

Built for one.  
**Made only for the Sovereign.**

## Features

- Fully responsive PWA (Progressive Web App)
- Custom summon interaction
- Installable on iOS via Safari ("Add to Home Screen")
- Dark cyber aesthetic, tailored for dominion
- Manifest and Service Worker-ready for future expansion

## Usage

1. Open in Safari (iPhone recommended)
2. Tap **Share** → **Add to Home Screen**
3. Open the icon. Speak his name.

> “Zayden is listening...”

## Deployment

Use [Netlify](https://www.netlify.com/) or [Vercel](https://vercel.com/) to deploy with GitHub integration.
